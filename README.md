# 尽览 · 使用指南

> 轻量、快捷的本地图片浏览与管理工具 · 无广告 · 不联网 · 照片数据不出你的电脑

---

## 尽览是什么

尽览（LightSee）是一款给 Windows 用的看图软件，把 ACDSee 的看图习惯和 Apple 的清爽设计放在了一起：左边文件夹、右边缩略图墙、双击看大图，顺手还能整理照片。它不弹广告、不上传照片、不需要登录，装完就能用，很适合管理家里电脑和手机备份出来的照片。

## 三步上手

- **第一步**：双击 LightSee.exe 打开软件（首次使用如提示缺少运行环境，按提示装一下免费的微软 .NET 桌面运行时即可）。
- **第二步**：在左侧栏点一个文件夹（快速访问里收着桌面、下载、图片等常用位置，底部还有各个磁盘盘符）。
- **第三步**：双击任意缩略图进入看图模式，方向键 ←→ 翻页，Esc 退出。

## 浏览与整理

### 文件夹与缩略图

- 左侧是文件夹树：顶部"快速访问"固定常用位置，往下是最近打开过的文件夹，最底部列出所有磁盘。
- 右侧是缩略图墙，工具栏可切换小 / 中 / 大三档，也能倒序排列。
- 几万张图的大文件夹也不卡：只渲染屏幕里看得见的那部分。

### 给照片打分、贴色标

- 选中照片后按数字键 0-5 打星（5 星最好，0 取消），卡片上会出现金色小星星。
- 右键"设置色标"给照片贴一个彩色圆点，比如红色=待处理、绿色=已精选。
- 右键"标签"可以勾选文字标签（如"家庭""风景"），同一张图可贴多个。

### 收藏夹

- 选中照片按 Ctrl+D，或点卡片右下角的星形图标，就能收进左侧"收藏夹"。
- 收藏夹里再按一次 Ctrl+D 取消收藏。照片改名、移动后收藏会自动跟着走。

### 智能相册

- 左侧"智能相册"组，点"＋ 新建智能相册"可以设一条自动规则，例如：
  "评级 3 星以上" + "仅收藏" + "2026 年拍摄"。
- 满足条件的照片会自动进相册，不用手动挑——相当于一张会自己更新的精选集。

### 人物（人脸整理）

- 点左侧"人物"组里的"＋ 扫描当前文件夹"，尽览会本地检测照片里的人脸，
  把长得像的自动归成一个人，侧栏出现"某某  N张"。
- 右键人物可以重命名（改成家人名字）、合并到另一个人、或忽略不想看到的人。
- 点某个人名，直接看 TA 出现的所有照片。
- 首次使用需要联网下载一个约 37MB 的识别模型，之后完全离线。人脸数据只存在
  本机索引里，不会上传。

### 找照片的三个帮手

- **文字搜索（OCR）**：工具 → 智能查找 → 文字搜索。它能"看懂"照片里的字——
  找一张写过字的截图、一张带店名的照片，输关键字就行。识别全部在本机完成。
- **查找重复图片**：工具 → 智能查找 → 查找重复图片。拍糊的连拍、重复保存的图
  一网打尽，按相似程度分档显示，确认后可清理。
- **按颜色筛选**：工具栏"颜色"按钮，按画面主色调找图——找一张"蓝色调的海"，选蓝色就好。

### 整理与批处理

- **批量重命名**：工具 → 整理 → 批量重命名，支持序号、原名、日期模板。
- **格式转换 / 图片压缩**：工具 → 处理，JPG / PNG / BMP / TIFF 互转、按画质压小体积。
- **右键批量工具**：可一键剥除照片里的隐私信息（GPS 定位、拍摄参数等），
  也能给图片加文字水印。
- **最近删除**：删除的照片会先进入软件内的回收站，保留 30 天，误删可找回。

## 看图

### 查看器

- 双击图片进入，←→ 翻页，滚轮缩放，按住拖动平移，双击在"适应窗口"和"100%"之间切换。
- 打开照片时会自动预加载前后各几张，翻页几乎无等待。
- F 全屏，空格键放幻灯片，M 打开放大镜检查细节，R / L 旋转，0 适应窗口，1 实际大小。

### 四种界面风格

查看器工具栏的"界面风格"按钮可随时切换，自动记忆：沉浸式极简（画面铺满，鼠标上移才浮出工具条）、现代简约（默认）、多面板模块化（右侧看拍摄参数）、复古精简。

### 拍摄信息与 GIF

- 多面板风格或状态栏里能看到相机型号、光圈、快门、ISO、GPS 等拍摄信息。
- 看 GIF 动图时底部有帧条，可逐帧查看、暂停播放，还能把某一帧保存成 PNG。

### 细心的画质处理

- **JPG 无损旋转**：右键使用，不重新压缩、画质零损失。
- **广色域照片**：用专业相机拍的广色域照片会自动校正颜色，不会发灰。

## 照片地图

- 工具栏"地图"按钮：把当前文件夹里带定位的照片放到地图上，悬停能看缩略图、
  拍摄时间和地名，点标记直接看大图。支持卫星图和标准地图切换。
- 手机拍的照片一般自带定位；没有定位信息的照片不会出现在地图上。
- 地图右上角"图"按钮可设置图源：卫星、矢量、路名三条地址都能改（内置高德
  为默认），支持带 Key 的图源（把 Key 直接写进地址即可）。换天地图等坐标
  系不同的图源时，记得取消"GCJ-02 纠偏"，否则标记会偏移约 500 米。改动
  立即生效并记住，"恢复默认"一键还原。

## 皮肤与外观

- 工具栏右侧"皮肤"按钮，七套配色随心换：晴空蓝（默认）、深海蓝调、靛蓝晨海、
  翡翠玉髓、杏暖橙、落日橙、晨雾玫瑰。
- 每套皮肤都配了淡淡的山水星河背景装饰，窗口角落若隐若现。
- 所有界面跟随皮肤联动，包括看图窗口和弹窗。

## 快捷键速查

- **0-5**：打星评级（0 取消）
- **Ctrl+D**：收藏 / 取消收藏
- **←→**：上一张 / 下一张
- **F**：全屏（Esc 退出）
- **空格**：幻灯片播放
- **M**：放大镜
- **+ / -**：缩放；**0** 适应窗口；**1** 实际大小
- **R / L**：右旋 / 左旋
- **Ctrl+O**：识别图片文字（OCR）
- **Esc**：退出看图 / 全屏

## 常见问题

- **会联网吗？** 平时完全离线。仅三处例外：首次下载人脸识别模型、地图功能的底图
  与地名查询、检查软件更新（如有）。浏览、看图、整理、OCR、人脸识别全部在本机完成。
- **怎么让双击图片默认用尽览打开？** 工具栏"关联"按钮，一键注册常用图片格式，
  同样一键可撤销。
- **删掉的照片去哪了？** 先进软件的"最近删除"（保存 30 天），清空后才进系统回收站。
- **设置存在哪？** 便携设计：配置跟软件走（exe 旁的 settings.json），换电脑拷走
  整个文件夹即可。遇到系统权限问题会自动改存用户目录。
- **绿色软件吗？** 是。不写注册表垃圾（文件关联除外，可一键撤销）、无后台进程、
  无自启动。
